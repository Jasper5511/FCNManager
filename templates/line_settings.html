設定 Messaging API
設定步驟：
  1. 前往 LINE Developers Console
  2. 建立 Provider（例如「投資服務」）
  3. 建立 Messaging API Channel（例如「市場日報」）
  4. 在 Channel 設定頁取得 Channel Secret
  5. 在 Messaging API 頁籤按 Issue 取得 Channel Access Token
  6. 在 Webhook 設定中填入：https://你的網域/line/webhook
